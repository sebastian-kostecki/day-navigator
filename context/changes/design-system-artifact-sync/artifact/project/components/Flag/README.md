# Flag

Obrysowana etykieta w wersalikach przy tytule pozycji, która mówi, dlaczego pozycja wymaga uwagi.

- `tone="change"` (`flag`, bursztyn): `ZMIENIONE` (ukryte wróciło po zmianie statusu lub cudzym komentarzu), `Z PIĄTKU` / `Z WCZORAJ` (przeniesione), `DZIŚ` (termin), `W DO ZROBIENIA`.
- `tone="new"` (`info`, niebieski): `NOWE` — nowe przypisanie.
- Najwyżej jedna flaga na wiersz. Bez wypełnienia — flaga nie konkuruje z przyciskiem primary.
