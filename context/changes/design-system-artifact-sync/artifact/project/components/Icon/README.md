# Icon

Kreskowa ikona 24×24 (obrys 2px, zaokrąglone końce) w `currentColor`, domyślnie 14px.

- Nazwy: `plus`, `close`, `refresh`, `edit`, `hide`, `show`, `external`, `chevron-left`, `chevron-right`, `wifi-off`, `alert`, `check-circle`, `repo`.
- Bez `label` ikona jest dekoracyjna (`aria-hidden`); w przycisku-ikonie nazwę daje `aria-label` przycisku.
- Kolor dziedziczy z rodzica: `ink` w przyciskach, `ink-faint` w nagłówku repozytorium, `danger` tylko w bloku błędu.
- Nie zastępuj ikon emoji ani znakami — wyjątkiem są glify stanu `● ○ ▲`.
