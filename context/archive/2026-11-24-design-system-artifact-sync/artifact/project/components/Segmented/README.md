# Segmented

Grupa 2–4 przełączanych przycisków w jednym obrysie `line-control`; wybrany segment `surface-active` + `ink-strong`, `aria-pressed`.

- Do wyboru jednej wartości bez zmiany widoku: Wszystko / Zgłoszenia / MR-y, Praca / Prywatne w formularzu zadania.
- Podaj `options`, `value`, `onChange` i `label` (nazwa grupy dla czytnika).
- `size="sm"` (domyślny) ma wysokość kontrolki (`size-control`); `size="md"` pasuje do pól 40px (`size-field`) — użyj go w rzędzie formularza obok `Field`.
- Do przełączania list z licznikami użyj `Tabs`, nie `Segmented`.
